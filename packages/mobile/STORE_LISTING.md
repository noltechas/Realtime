## Description (max 4000 chars)
```
Realtime Karaoke turns any get-together into a live karaoke show.

Join a session by scanning the host's QR code — no account, no sign-up. Once you're in, the night runs from your phone:

BROWSE & QUEUE
Flip through the song catalog and add yourself to the queue with a tap. Set up solo songs or split parts between multiple singers.

VOTE ON WHAT'S NEXT
The queue is democratic. Upvote the songs you want to hear and watch the lineup reorder in real time.

REACT LIVE
Send emojis, reactions, and cheers to the stage display while your friends perform. Hype up the room from your seat.

REQUEST SONGS
Can't find a track? Send a request to the host and they'll add it to the library.

MAKE IT YOURS
Pick a profile photo and a signature color that follows you across the queue and stage.

AWARDS
Hand out end-of-night awards and vote on the winners — best performance, most improved, and more.

Realtime Karaoke pairs with a host running the Realtime Karaoke desktop app, which plays the music and displays synced lyrics on a TV or projector. This companion app is how everyone in the room joins in and takes part.

Built for house parties, game nights, and anyone who'd rather sing with friends than scroll alone.
```

## App Review Information — Review Notes
```
Realtime Karaoke is a companion app for a private, personal-use karaoke setup shared among friends. The flow is QR-code based — there is no login or account.

HOW IT WORKS:
The mobile app pairs with a host running the separate Realtime Karaoke desktop application, which plays music and shows lyrics on a TV. Guests use this iPhone app to join the host's session, browse songs, queue up, vote, and send reactions.

TO TEST THE APP STANDALONE:
1. Launch the app — it opens to a join screen with a QR scanner.
2. Without a live host session, the scanner has nothing to connect to, so the app will show its waiting / no-session state. This is expected.
3. The full multi-user experience (queue, voting, reactions) requires a live host session created on the desktop app, which is not publicly distributed.

LIVE DEMO SESSION FOR REVIEW:
We will keep a demo session running during review. Use this session code to join and exercise the full app:

The app launches and renders its full UI independently; only the live session features require the host. Please reach out at noltechas@gmail.com with any questions — happy to do a screen-share demo.
